# Тәфсир дәресләре

30 нчы җүзнең 37 сүрәсе һәм Әл Фатиха сүрәсе буенча кабатлау һәм белемне тикшерү сайты.

Сайтта 38 сүрә, 312 ябык сорау һәм һәр сүрә өчен бер соңгы ачык сорау бар. Сораулар экспертлар тикшергән Word файлларыннан алынган.

## Эчтәлекне яңарту

Сораулар һәм җаваплар `surahs.js` файлында саклана. Сорау, вариантлар, дөрес җавап яки нигезләү үзгәртелгәннән соң сайтны яңадан бастырырга кирәк. Сүрәләрнең адреслары үзгәрми.
