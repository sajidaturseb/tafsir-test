# Тәфсир дәресләре

30 нчы җүзнең 37 сүрәсе, Әл-Фатиха һәм 29 нчы җүздән Әл-Мурсәләт белән Әл-Инсан дәресләре буенча кабатлау һәм белемне тикшерү сайты.

Әл-Инсан сүрәсе 4, 5 һәм 6 нчы дәресләр итеп өч аерым биткә бүленгән: 1–10, 11–22, 23–31 нче аятьләр. Һәр дәрестә биш уйлану соравы, биш тест соравы һәм бер соңгы ачык җавап бар. Төп текст һәм сораулар расланган Word файлларыннан алынган.

## Эчтәлекне яңарту

Сораулар һәм җаваплар `surahs.js` файлында саклана. Сорау, вариантлар, дөрес җавап яки нигезләү үзгәртелгәннән соң сайтны яңадан бастырырга кирәк. Сүрәләрнең адреслары үзгәрми.
